| Subsystem                        | Tool & Command One-Liner                                                                | Common Flags Used                                                                                                                                                                                     | Kernel Metric Measured                                                                                                                                                                                                   | Diagnostic Interpretation (What High/Abnormal Values Indicate)                                                                                                                                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CPU                              | perf — `sudo perf stat -a -e cycles,instructions,cache-references,cache-misses sleep 5` | `-a` (all CPUs), `-e` (select events), `-p PID` (process), `-r N` (repeat), `-I 1000` (interval in ms), `-d` (detailed statistics)                                                                    | Hardware Performance Monitoring Unit (PMU) counters: CPU cycles, instructions retired, cache references, cache misses, instructions per cycle (IPC).                                                                     | High cache-miss rates indicate poor cache locality or memory access bottlenecks. Low IPC may indicate memory stalls, branch mispredictions, or inefficient instruction execution. High cycles with low instruction throughput suggest CPU inefficiency.                                                               |
| Storage                          | iostat — `iostat -xz 1 5`                                                               | `-x` (extended device statistics), `-z` (omit inactive devices), `-k` (KB/s), `-m` (MB/s), `-d` (device report), `-y` (omit first report since boot)                                                  | Block-device statistics from `/proc/diskstats`: read/write throughput, IOPS, average request size, average queue size (`aqu-sz`), request latency (`await`), and device utilisation (`%util`).                           | High `await` indicates increased I/O latency. High `aqu-sz` indicates queued I/O requests. Sustained high `%util` can indicate device saturation, particularly on devices with limited parallelism.                                                                                                                   |
| Memory                           | vmstat — `vmstat -w 1 5`                                                                | `-w` (wide output), `-a` (active/inactive memory), `-s` (memory statistics), `-m` (slab information), `-d` (disk statistics), `-n` (single header)                                                    | Virtual memory and process statistics from `/proc/meminfo`, `/proc/vmstat`, and `/proc/stat`: free memory, swap activity (`si`, `so`), page scanning (`in`, `out`), blocked processes (`b`), and CPU wait time (`wa`).   | Sustained non-zero `si` and `so` indicate active swapping. High `r` indicates CPU scheduling pressure. High `b` suggests tasks blocked on I/O. High `wa` indicates CPU time associated with outstanding I/O waits.                                                                                                    |
| CPU / Memory / Storage / Network | sar — `sar -u -r -S -d -n DEV 1 5`                                                      | `-u` (CPU utilisation), `-r` (memory utilisation), `-S` (swap space), `-d` (block-device activity), `-n DEV` (network interfaces), `-q` (load and queue statistics), `-B` (paging statistics)         | System activity statistics collected from kernel interfaces: CPU time percentages, memory and swap usage, paging, block-device I/O, network throughput, packet rates, and run-queue activity.                            | High `%user` or `%system` indicates CPU workload pressure. High `%memused` indicates memory pressure when accompanied by reclaim or swapping. High `%iowait` suggests I/O delays. High network errors or drops indicate interface, driver, buffer, or congestion problems.                                            |
| Network                          | ss — `ss -s && ss -tanop`                                                               | `-s` (socket summary), `-t` (TCP), `-u` (UDP), `-a` (all sockets), `-n` (numeric addresses), `-o` (TCP timers), `-p` (process information), `-i` (TCP internal information), `-l` (listening sockets) | Kernel socket and TCP state information from the networking stack and socket diagnostic interfaces: connection states, receive/send queue sizes, retransmission timers, TCP congestion control, and socket memory usage. | High `SYN-RECV` counts may indicate connection floods or incomplete handshakes. Persistent `TIME-WAIT` accumulation may indicate high connection churn. Large `Send-Q` indicates queued outbound data; large `Recv-Q` on established sockets indicates the application is not consuming incoming data quickly enough. |
